# The Mathy Professor 🧮

Contained within are mathematical practice scripts designed with readability and user experience in mind.

## Current Features
* **`F_to_C.py`**: Interactive Fahrenheit to Celsius converter.
* **`C_to_F.py`**: Interactive Celsius to Fahrenheit converter.

## How to Run
Navigate to this directory in your terminal and run:
```powershell
python F_to_C.py
